# Roadmap

## Completed Milestones

- Project Setup: created the repository structure, packaging, configuration files, and initial documentation.
- Core Framework: implemented the Python package foundation, CLI entry points, and shared utilities.
- Collector Architecture: introduced collector abstractions, a registry, company models, validators, and supporting tests.

## Planned Milestones

- Company Master Collector: add the first real collector for company master data.
- Financial Collectors: extend the system with collectors for financial and market data.
- Scoring Engine: implement the scoring layer that evaluates collected data.
- Reports: generate structured outputs for analysis and presentation.
- Dashboard: provide a richer interface for viewing results and trends.
